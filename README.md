# Pong

A simple Pong game made with java

# How to play

1. Download the latest `.jar` file from the [Releases]([https://github.com/your-username/your-repo-name/releases](https://github.com/GamingChefDude/Pong/releases/tag/v.1.0)) tab.
2. Click it (It starts to download).
3. Click the download and play.
4. Have fun!
